# KernelEngine

A microkernel game engine: ABI-stable C contracts, Zig plugins behind them, and a managed C#
layer for game code.

- **Guides** show how to use the engine, quoting examples the build compiles.
- **Architecture** has one map per domain: its parts and what each hands to which.
- **Decisions** records why a structural choice was made, one file per decision.
- **Conventions** are the rules the code and the documents are written to.
- **Formats** describe the files the engine reads.
- **Reference** is generated from the doc comments of the sources: one page per file.
